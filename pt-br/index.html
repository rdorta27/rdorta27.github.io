Como trabalho

O LLM lida com a linguagem. As regras moram no código.

No Sentinel Engine, o modelo só rotula a intenção: mascaramento, política, confirmação e criação do caso são código. No Knowman, um limiar de distância decide o que conta como evidência; fora dele, o modelo nunca é chamado.

Nada segue para frente antes de passar por uma avaliação.

O Sentinel Engine só serve um prompt depois de um conjunto selado de avaliação em dados de retenção passar os seus gates de aceitação. O Knowman guarda cada execução de avaliação, então uma regressão aparece como uma queda.

Local-first, com evidência verificável.

O Knowman roda sobre Postgres, pgvector e Ollama na máquina. O Flow Audit trabalha a partir de exportações de evidências. O Sentinel Engine publica execuções congeladas, cada uma com os seus scripts e um summary.json.
