How I work

The LLM handles the language. The rules live in code.

In Sentinel Engine, the model only labels the intent: masking, policy, confirmation and case creation are code. In Knowman, a distance threshold decides what counts as evidence; outside it, the model is never called.

Nothing ships before it passes an evaluation.

Sentinel Engine serves a prompt only after a sealed held-out evaluation passes its acceptance gates. Knowman stores every eval run, so a regression shows up as a drop.

Local-first, with verifiable evidence.

Knowman runs on Postgres, pgvector and Ollama on the machine. Flow Audit works from evidence exports. Sentinel Engine publishes frozen evaluation runs, each with its scripts and a summary.json.
